# L&M PC Computadoras
Documentación actualizada con las nuevas funcionalidades de comercio electrónico implementadas en el proyecto. Se han agregado secciones sobre catálogo de productos, carrito de compras, gestión de inventario y APIs correspondientes.

Características nuevas documentadas:
- Catálogo de productos por marcas (ASUS, HP/Dell, Lenovo, MSI, Omnilbook, PC)
- Sistema de carrito de compras con validación de stock
- Gestión de inventario en tiempo real
- APIs para operaciones del carrito
- Nueva tabla de productos en la base de datos

Fecha de actualización: Febrero 2026
